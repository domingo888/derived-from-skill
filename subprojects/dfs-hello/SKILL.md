# DFS Hello

## 目标

根据给定姓名，生成一句中文礼貌问候语。

## 输入

- `name`（string，必填，1–40 字）：被问候的人名。

## 输出

- `greeting`（string）：一句完整的中文问候，必须原样包含 `name`。

## 流程

1. 读取 `name`。
2. 生成一句中文礼貌问候，包含这个名字，不加引号、不加解释。
3. 校验：`greeting` 非空，且包含 `name` 原文。

## 边界

- 只输出一句话，不附加建议、不追问、不扩展话题。
- `name` 为空或超过 40 字：由输入 schema 拦截，不进入流程。

## 失败处理

- 生成的文本若不包含 `name`，判定失败，不降级输出、不改写结果。
